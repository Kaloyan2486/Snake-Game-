# Snake Game

Класическата игра Snake, направена с Python и tkinter.

## Описание

Змията се движи по екрана и яде храна. При всеки изяден плод резултатът се увеличава с 1. Играта свършва когато змията удари стена или себе си. След края на играта може да започнеш отново с бутона **PLAY AGAIN**.

## Структура на проекта

```
Snake_Game/
├── main.py          # Главен файл — стартира играта и управлява логиката
├── models.py        # Класовете Snake и Food
```

## Настройки

Всички настройки се намират в началото на `models.py`:

| Настройка | Стойност | Описание |
|-----------|----------|----------|
| `GAME_WIDTH` | 1700 | Ширина на полето в пиксели |
| `GAME_HEIGHT` | 1000 | Височина на полето в пиксели |
| `SPEED` | 100 | Скорост (по-малко = по-бързо) |
| `SPACE_SIZE` | 50 | Размер на блок в пиксели |
| `BODY_PARTS` | 3 | Начален брой части на змията |
| `HEAD_COLOR` | #0C7936 | Цвят на главата |
| `SNAKE_COLOR` | #692929 | Цвят на тялото |
| `FOOD_COLOR` | #FF0000 | Цвят на храната |

## Как се стартира

1. Увери се че имаш инсталиран Python 3
2. Стартирай играта:
```
python main.py
```

## Управление

| Клавиш | Действие |
|--------|----------|
| Стрелка нагоре | Движи нагоре |
| Стрелка надолу | Движи надолу |
| Стрелка наляво | Движи наляво |
| Стрелка надясно | Движи надясно |

## Използвани библиотеки

- `tkinter` — вградена Python библиотека за графичен интерфейс
- `random` — вградена Python библиотека за случайни числа

> Няма нужда от допълнителна инсталация — двете библиотеки са вградени в Python.
